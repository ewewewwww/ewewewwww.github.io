Privacy Policy

Last updated: October 16, 2026

AMAPLA Uploader ("the tool") is a personal desktop tool used only by the owner of the AMAPLA channel to upload their own videos to their own accounts.

What data the tool uses

  • Access tokens for the owner's own Instagram, Facebook Page and TikTok accounts, used only to upload the owner's videos.
  • The owner's own video files and captions.

Where data is stored

All tokens and files are stored only on the owner's own computer. The tool has no server and does not collect, sell or share any data with third parties, other than sending videos to the platforms the owner chooses (Instagram, Facebook, TikTok).

Other people's data

The tool does not access, collect or store data about any other users.

Deleting data

The owner can delete all stored data at any time by deleting the tool's folder, and can revoke access from each platform's account settings.
